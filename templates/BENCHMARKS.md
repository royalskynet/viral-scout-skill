# 對標清單（YouTube Shorts）

頭部頻道與中位數，90 天內可直接引用。排名依最近 30 支 Shorts 的播放中位數，不是訂閱數——訂閱數是歷史，中位數才是現在的分發力。
離群＝發現那支的播放 ÷ 該頻道中位數；離群 ≥×5 才算這題本身會爆，不然只是頻道大。

來源：YouTube Data API `search.list`（`order=viewCount`，近 90 天）找候選頻道，再量每個頻道的 Shorts 頁。配額 search 每次 100 單位、日上限 1 萬，所以一天只跑一次。
